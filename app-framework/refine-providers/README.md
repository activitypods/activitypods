# @activitypods/refine-providers

Auth, data and live providers to connect [Refine](https://refine.dev) apps to [ActivityPods](https://activitypods.org) Pods.

See the [documentation](https://docs.activitypods.org/app-framework/frontend/introduction/).

## Commands

```bash
yarn build
yarn watch
```

Versioning and publication are handled from the `app-framework` directory.
